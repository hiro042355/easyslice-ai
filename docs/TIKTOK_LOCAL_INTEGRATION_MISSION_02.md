## Durable OAuth state

Only tests/tiktokIntegration/fixtures/LOCAL_TEST_ONLY.sql creates the isolated schema. No production SQL directory or migration number is used. Runtime uses a distinct non-superuser, non-owner, NOINHERIT role with intended-schema DML, no database/schema CREATE authority. Values use pg protocol parameters; identifiers/statements are fixed. The fixture owner's role password is generated random hex and passed through psql's literal quoting, never a shell argument/log or tracked file.

State is randomBytes(32), canonical 43-character base64url; only its SHA-256 digest is persisted, uniquely constrained. Database-clock issuance/expiry limits it to ten minutes and the verified session's absolute expiry. Bindings are UID, verified session hash, synthetic app, sandbox environment, canonical requested-scope digest and exact local callback URI. Atomic conditional UPDATE claims PENDING once and returns a claim nonce. One database, rather than process memory, arbitrates independent service/pool instances. Claimed -> consumed/failed is terminal; SQL triggers reject reopening. No regeneration/retry after duplicate state or failed exchange.

The callback validates method, exact local origin/path, unique/bounded state/code/error shape and bindings, then claims before invoking the mock provider. Provider denial and invalid replies fail terminally. Tokens and state consumption commit in one database transaction; custody failure rolls back the consumed transition and the service attempts only terminal failure marking. A lost/ambiguous database result may remain CLAIMED and is never reopened or automatically retried. Cleanup destroys this test database, not a Production transaction history.

Start/disconnect require same-origin and a session-bound HMAC CSRF header. Start accepts no body overrides. Disconnect requires explicit confirm=true. GET connection requires authentication and returns no-store version/status/display name only. Raw state occurs only in the synthetic authorization redirect/callback protocol; never token JSON, UI props or storage. Token values never occur in query strings. Native callback ignores inputs and cannot exchange codes.

## Custody

AES-256-GCM uses a random 12-byte nonce, 16-byte tag and injected local key provider. Ephemeral random 32-byte keys never enter Git or database storage. Persisted fields are key ID, nonce, ciphertext, tag and ownership/expiry/scope metadata. AAD binds UID, open_id, app, environment, connection generation, expiry, scopes and key ID. Tampering, key mismatch, wrong owner/environment, revocation and expiry reject. Plaintext access/refresh tokens are synthetic-only, resolved inside server code for an approved mock operation; they are never projected to browser JSON or error messages. Public custody serialization contains safe classifications only. There is no automatic refresh; expiry means REAUTH_REQUIRED.

Disconnect terminalizes outstanding state, marks connection revoked, erases ciphertext/nonce/tag and invalidates pending/claimed grants in one local transaction. Reconnection creates a new generation, so old grants cannot authorize it. Disconnect is local mock revocation; it makes no provider revoke request and does not claim remote revocation.
